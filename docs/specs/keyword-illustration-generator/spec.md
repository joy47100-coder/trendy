# 미감 테스트 (일러스트 투표)

## 사용자에게 보이는 결과

- 웹페이지에 접속하면 로그인 없이 바로 테스트를 시작할 수 있다.
- 키워드마다 화풍 풀(8가지) 중 무작위로 뽑힌 5가지 후보가 보이고, 그중 마음에 드는 1장을 고른다. 매번 같은 5개만 나오면 지루하다는 이유로, 뽑히는 화풍 조합은 볼 때마다 달라진다.
- "다음"을 누르면 다음 키워드로 넘어간다. 모든 키워드를 다 고르면 결과 화면이 나온다.
- 결과 화면에서는 키워드마다 "내 선택"과 "지금까지 가장 많이 선택된 그림"을 나란히 보여주고, 몇 개나 다수 의견과 일치했는지 알려준다.

## 승인된 범위

- 정적 일러스트 카탈로그: 키워드 5개 × 화풍 8가지 = 총 40장. Claude Code 세션에서 Claude가 화풍마다 다르게 그리고, 화풍별 최적 포맷(SVG 또는 PNG)으로 저장한다.
- 로그인 없는 공개 투표 흐름: 키워드마다 화풍 풀에서 5개를 무작위로 뽑아 보여주고 그중 1장 선택 → 다음 → 전체 완료 시 결과 화면
- 투표 결과를 Supabase에 누적 저장하고, 결과 화면에서 다수 의견과 비교
- "다시 하기"로 처음부터 다시 진행
- 범위 제외 (토이 프로젝트 단계에서 보류): 앱 안에서의 일러스트 자동 생성, 득표 상위 결과 다운로드, 라벨 칸 토글, 미리캔버스 자동 업로드, 회원가입, 부정 투표 방지(중복 투표 차단 등)

## 관찰 가능한 수용 기준

**일러스트 (정적 파일)**
- 각 키워드 폴더에 화풍 8가지로 그린 후보가 있다.
- 각 이미지는 완전 투명 배경이며, 피사체 기준 여백 없이 크롭되어 있고, 하나의 피사체만 담고 있다.
- 각 이미지는 색상을 5개 이하로 사용한다.
- 인접한 색 영역 사이에 렌더링 시 보이는 틈(크랙)이 없다.
- 한 키워드 안의 후보들은 같은 화풍이 아니라 서로 다른 화풍(손그림 플랫·미니멀 라인아트·기하학 페이퍼컷·수채화 번짐·레트로 스티커·픽셀아트·네온 글로우 라인·콜라주 스크랩북)으로 그려져 있어, 구도가 아니라 화풍 자체를 비교하게 한다.
- 손그림 플랫·미니멀 라인아트·기하학 페이퍼컷·픽셀아트·네온 글로우 라인은 SVG(150KB 이하)로, 수채화 번짐·레트로 스티커·콜라주 스크랩북은 PNG(1500px 이상, dpi 정보 포함)로 저장되어 있다 (미리캔버스 SVG/PNG 요소 규격 기준). SVG로 지정된 화풍이라도 실제 파일이 150KB를 넘으면 그 파일만 PNG로 대체된다.
- `lib/illustration/candidate-formats.json`에 후보별 최종 포맷(svg/png)이 기록되어 있고, 화면은 이 값을 따라 정확한 확장자로 이미지를 요청한다.

**투표 흐름**
- 첫 화면에 첫 번째 키워드와, 화풍 8가지 풀 중 무작위로 뽑힌 5가지 후보, 진행 상황(1/5)이 보인다.
- 같은 키워드라도 방문할 때마다(또는 방문자마다) 어떤 5가지 화풍이 뽑히는지는 달라질 수 있다.
- 아무것도 고르지 않으면 "다음" 버튼이 비활성화된다.
- 후보를 고르면 선택한 카드에 테두리 표시가 되고 "다음" 버튼이 활성화된다.
- "다음"을 누르면 다음 키워드로 넘어가고 진행 상황이 갱신된다.
- 마지막 키워드에서는 버튼 문구가 "결과 보기"로 바뀐다.
- "결과 보기"를 누르면 선택 5건이 한 번에 저장되고 결과 화면으로 넘어간다.

**결과 화면**
- 키워드마다 "내 선택"과 "다수 선택" 썸네일이 나란히 보인다.
- 키워드마다 다수 의견과 같은지 다른지 문구로 표시된다.
- 상단에 몇 개가 일치했는지(예: 3/5) 표시된다.
- 아직 아무 표도 없는 키워드는 "다수 선택"을 보여주지 않는다.
- "다시 하기"를 누르면 첫 키워드로 돌아가고 선택이 초기화된다.

**오류 처리**
- Supabase 설정이 없으면 결과 저장 시 안내 문구가 화면에 표시되고, 원시 JS 오류가 노출되지 않는다.

## 확정된 제약과 근거

- 일러스트는 런타임 API 호출이 아니라 Claude가 미리 그려둔 정적 파일이다. [ai-image-backend 결정](../../decisions/ai-image-backend.md) 참고.
- 서빙·저장 형식은 화풍별로 다르다(손그림 플랫·미니멀 라인아트·기하학 페이퍼컷·픽셀아트·네온 글로우 라인=SVG, 수채화 번짐·레트로 스티커·콜라주 스크랩북=PNG). Claude는 모든 화풍을 SVG로 그리고, `scripts/build-illustration-formats.mjs`가 화풍별 규칙에 따라 최종 포맷을 정해 `lib/illustration/candidate-formats.json`에 기록한다. [output-file-format 결정](../../decisions/output-file-format.md) 참고.
- 파일 규격은 미리캔버스 디자인허브 SVG/PNG 요소 가이드를 따른다 (완전 투명 배경, 단일 피사체, 여백 없는 크롭, 색상 5개 이하, 색 경계 크랙 방지; SVG는 6000px 이하·72dpi 이상·150KB 이하; PNG는 1500~9800px·120dpi 이상·50MB 이하).
- 한 키워드의 후보는 서로 다른 화풍으로 그린다. "미감 테스트"라는 컨셉 자체가 화풍 취향을 비교하는 것이기 때문이다 (사용자가 명시적으로 방향을 바꿈 — 처음엔 "같은 화풍, 다른 구도"였다가 "다른 화풍끼리 비교"로 확정).
- 화풍 풀은 8개(손그림 플랫·미니멀 라인아트·기하학 페이퍼컷·수채화 번짐·레트로 스티커·픽셀아트·네온 글로우 라인·콜라주 스크랩북)이고, 방문 때마다 이 중 5개를 무작위로 뽑아 보여준다. 매번 같은 5개만 나오면 지루하다는 사용자 피드백으로 5개 고정에서 8개 풀로 확장했다. 정의는 [illustration-style 결정](../../decisions/illustration-style.md) 참고.
- 투표 결과는 Supabase에 저장한다. [vote-data-store 결정](../../decisions/vote-data-store.md) 참고.
- 투표는 로그인 없이 누구나 참여할 수 있다.
- 이번 스펙은 토이 프로젝트 단계다. 사용자가 "일단 만들어놓고 나중에 직접 이어서 개발하겠다"고 명시했으므로, 다운로드·라벨 칸처럼 이미 문서화된 기능도 이번엔 구현하지 않고 범위 밖으로 둔다.

## 남겨둔 가정

- 키워드는 맥주·커피·자전거·고양이·케이크 5개로 시작한다. `lib/illustration/catalog.ts`에서 쉽게 바꿀 수 있게 둔다. 다음 키워드 후보는 `trend-keyword-research` 스킬로 조사할 수 있다 ([keyword-sourcing 결정](../../decisions/keyword-sourcing.md) 참고). 이 스킬은 후보만 제시하고 카탈로그를 자동으로 고치지 않는다.
- 투표는 마지막 단계에서 5건을 한 번에 저장한다. 중간에 그만두면 아무 표도 저장되지 않는다. 요청 수를 줄이고 "완주한 사람의 표"만 집계하기 위한 선택이다.
- 득표가 동점이면 인덱스가 작은 후보(화풍 번호가 빠른 쪽)를 다수 선택으로 취급한다.
- 투표 한 건은 익명으로 기록하고, 같은 사람이 여러 번 투표하는 것을 막는 장치는 만들지 않는다.
- 화풍·형식 규칙은 `lib/illustration/style-guide.ts`에 남겨두어, 나중에 그림을 더 그릴 때 같은 지침을 재사용할 수 있게 한다.
- PNG로 나가는 화풍(수채화 번짐·레트로 스티커·콜라주 스크랩북)은 2000×2000px, 144dpi로 만든다. 미리캔버스 일러스트 규격(1500~9800px, 120dpi 이상) 안에 여유 있게 들어가는 값으로 에이전트가 정했다.
- 방문자에게 보여줄 5개는 클라이언트에서 매 방문마다 무작위로 뽑는다(서버가 미리 정해서 내려주지 않음). 득표 집계는 화풍 id 기준으로 전체 풀(8개)을 대상으로 하므로, 어떤 5개가 뽑히든 "전체 투표 중 몇 %" 같은 집계에는 영향이 없다.

## 범위 밖과 이유

- 앱 안에서의 일러스트 자동 생성: 사용자가 별도 API 키 없이 가는 방식을 선택했다. 그림 추가는 Claude Code 세션에서 수동으로 한다.
- 득표 상위 결과 다운로드, 라벨 칸 토글: 사용자가 "일단 토이 프로젝트로 만들어놓고 나중에 직접 이어서 개발하겠다"고 명시적으로 범위에서 뺐다.
- 미리캔버스 자동 업로드·연동: PRODUCT.md에서 나중 확장으로 미뤘다.
- 회원가입·로그인: 투표는 누구나 로그인 없이 참여하는 것으로 정했다.
- 미리캔버스 외 다른 판매 플랫폼 대응: 범위 밖이다.
- 부정 투표 방지(중복 투표 차단, 봇 방지 등): 스펙이 요구하지 않는 보안 하드닝으로 범위 밖이다.

## 남은 리스크

- 미리캔버스 심사 기준(구도가 실질적으로 다른지, 독창성이 충분한지)은 사람이 최종 판단하는 영역이라, 이 그림들이 실제로 심사를 통과할지는 확인할 수 없다.
- 투표가 쌓이기 전에는 "다수 의견"이 사실상 무의미하다. 표본이 적을 때의 안내는 지금 다루지 않는다.
- Supabase 무료 티어 한도를 넘는 트래픽이 몰리면 투표 저장이 실패할 수 있다.
- PNG로 나가는 화풍(수채화 번짐·레트로 스티커)은 색상을 구매자가 커스터마이징할 수 없다. SVG로 나가는 세 화풍은 가능하다.
