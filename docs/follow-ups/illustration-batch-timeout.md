# 일러스트 배치 생성이 서버리스 타임아웃을 초과할 위험

## 증상

`app/api/illustrations/route.ts`는 POST 요청 하나 안에서 최대 100장(키워드 10개 × 10장)을
동시성 4로 순차적으로 생성한다. 스트리밍이나 백그라운드 작업 분리가 없다.

## 근거

- `code-review low` 통과: Opus 5 호출이 thinking을 포함해 건당 5~15초 걸린다고 가정하면,
  25라운드(100장 ÷ 동시성 4) 실행 시 총 소요 시간이 수 분에 이를 수 있다.
- 로컬 `next dev`에는 타임아웃이 없어 이 문제는 재현되지 않았다. 실제 Vercel 배포
  환경(기본/Pro 플랜의 함수 실행 시간 제한)에서만 드러난다.

## 시도한 것

없음 — 로컬 검증만 했고, 아직 실제 배포로 재현해보지 않았다.

## 제안하는 다음 단계

배포 후 실제로 재현되는지 확인하고, 재현되면 다음 중 하나를 검토한다.
- 진행 상황을 스트리밍(SSE 등)으로 보내 클라이언트가 부분 결과를 먼저 받게 하기
- 배치를 여러 개의 짧은 요청으로 쪼개기 (예: 키워드 1개씩)
- Vercel의 더 긴 함수 실행 시간 플랜/설정 사용
