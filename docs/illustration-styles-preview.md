# 미감 테스트 - 5개 화풍

같은 키워드(맥주, 커피, 자전거, 고양이, 케이크)를 아래 5가지 화풍으로 각각 그려서, 방문자가 어느 화풍을 예쁘다고 느끼는지 비교합니다.

## 1. 손그림 플랫
- 손으로 그린 듯 살짝 불완전하고 흔들리는 윤곽선
- 두껍고 둥근 어두운 윤곽선 + 안쪽은 따뜻한 색의 평평한 단색
- 인상: 친근하고 포근함

## 2. 미니멀 라인아트
- 선으로만 그림 (면 채우기 없음, 포인트 색 한 곳만 예외)
- 굵기 일정한 가는 선, 디테일 과감히 생략
- 인상: 담백하고 세련됨

## 3. 기하학 페이퍼컷
- 윤곽선 없이 색 면(fill)만으로 형태 구성
- 원·삼각형·사다리꼴 같은 단순 도형을 종이 오려붙인 듯 겹침
- 인상: 모던하고 그래픽적

## 4. 수채화 번짐
- 윤곽선 없이 부드러운 유기적 곡선만 사용
- 반투명 색 레이어를 살짝 어긋나게 겹쳐 번짐 효과
- 채도 낮은 차분한 색 (더스티 로즈, 세이지, 오커, 슬레이트 블루)
- 인상: 은은하고 손그림 물감 같음

## 5. 레트로 스티커
- 실루엣을 따라 두꺼운 흰색 다이컷 테두리 + 그 위에 대담한 평면 채색
- 70년대풍 배색 (머스터드, 브릭레드, 틸, 크림, 다크브라운)
- 굵은 줄무늬나 반짝임 선 같은 레트로 장식
- 인상: 강렬하고 뱃지 같음
