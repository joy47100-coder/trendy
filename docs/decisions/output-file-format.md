# 생성 결과물 파일 형식

## Decisions

- 화풍마다 최적 포맷을 다르게 쓴다. 손그림 플랫·미니멀 라인아트·기하학 페이퍼컷은 SVG, 수채화 번짐·레트로 스티커는 PNG. 매핑은 `lib/illustration/style-guide.ts`의 `STYLES[].preferredFormat`에 코드로 남긴다.
- SVG로 지정된 화풍이라도 실제 파일이 150KB를 넘으면 그 파일 하나만 PNG로 폴백한다.
- Claude는 모든 화풍을 SVG 마크업으로 그린다. `scripts/build-illustration-formats.mjs`가 화풍별 규칙에 따라 최종 포맷을 정해 `public/illustrations/<slug>/<n>.{svg,png}`를 만들고, 어떤 후보가 어느 포맷인지 `lib/illustration/candidate-formats.json`에 기록한다. 앱은 이 매니페스트를 보고 확장자를 정한다.

## Boundaries

- 미리캔버스 디자인허브 제출용 일러스트 파일에만 적용된다.
- 같은 디자인을 PNG와 SVG 둘 다로 제출할 수 없다는 미리캔버스 규정과 맞물려, 후보 하나(키워드×화풍 하나)는 항상 SVG 또는 PNG 중 하나로만 최종 확정된다.

## Why

이전엔 SVG의 150KB 제한이 부담스러워 "SVG는 포기하고 PNG만 쓴다"로 정했었다. 그런데 사용자가 검토를 요청한 skill.md가 화풍별로 이미 검증된 포맷 매핑을 제시했고, 그 기준(그림자·질감 없는 화풍은 SVG, 반투명 레이어나 텍스처가 많은 화풍은 PNG)이 합리적이라 다시 채택했다. 실측 결과 손그림 플랫·미니멀 라인아트·기하학 페이퍼컷의 SVG 25개 중 가장 큰 파일도 3.8KB로, 150KB 한도에 전혀 안 걸린다 — "SVG가 부담스럽다"는 이전 결정의 전제가 이 세 화풍에는 애초에 해당하지 않았던 것이다. SVG로 나가는 화풍은 벡터라 구매자가 색상을 커스터마이징할 수 있다는 이점도 되살아난다.

## Reconsider when

- 손그림 플랫·미니멀 라인아트·기하학 페이퍼컷 화풍의 실제 SVG 용량이 150KB에 자주 걸리기 시작할 때 (그때는 다시 PNG 통일을 검토).
- 수채화 번짐·기하학 페이퍼컷에 그림자·텍스처 같은 요소가 추가돼 SVG로 표현하기 어려워질 때.
- 미리캔버스가 PNG나 SVG 규격을 바꿀 때.

## Still-rejected alternatives

- 5개 화풍 전부 PNG로 통일 (직전 결정) — SVG 150KB 제한을 우려해 택했었지만, 실제로는 세 화풍 모두 그 한도에 전혀 안 걸려 과도한 제약이었다; skill.md의 화풍별 매핑을 검토한 뒤 뒤집었다.
- AI가 래스터를 직접 생성(OpenAI Images API 등) — [ai-image-backend 결정](ai-image-backend.md)에서 별도 API 키가 필요 없는 "Claude가 직접 그리기" 방식을 택했으므로 무관.

## Evidence worth preserving

- 미리캔버스 디자인허브 SVG 요소 규격: 최대 6000px, 72dpi 이상, **최대 150KB**. 150KB를 넘으면 PNG로 제출해야 한다. 사용자가 색상을 커스터마이징할 수 있도록 색상이 정리되어 있어야 한다.
- 미리캔버스 디자인허브 PNG(일러스트) 요소 규격: 1500~9800px, 120dpi 이상, 50MB 이하. (아이콘/이모티콘/캐릭터는 700~9800px.) PNG로 나가는 화풍은 2000×2000px, 144dpi로 만들어 이 범위 안에 여유 있게 들어간다.
- 실측: 손그림 플랫·미니멀 라인아트·기하학 페이퍼컷 SVG 25개(5키워드×3화풍)의 최대 파일 크기는 3.8KB(`bicycle/1.svg`)로, 150KB 한도의 3% 미만이다.
- 참고로 확인한 다른 카테고리 규격 (지금 범위에는 미적용): PNG(오브젝트 중심, 배경 제거) 2500~9800px·120dpi 이상·50MB 이하; JPG(사진, 인물·재산권 포함 가능) 2500~9800px·120dpi 이상·50MB 이하; JPG(피사체 없는 이미지) 2500~9800px·120dpi 이상·50MB 이하; GIF(움직이는 콘텐츠) 700~1920px·72dpi 이상·25MB 이하.
