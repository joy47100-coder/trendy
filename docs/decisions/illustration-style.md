# 일러스트 화풍

## Decisions

- "미감 테스트"에서는 화풍을 통일하지 않는다. 같은 키워드를 여러 화풍으로 각각 그려서 화풍 취향 자체를 비교한다.
- 화풍 풀은 여덟 가지: 손그림 플랫, 미니멀 라인아트, 기하학 페이퍼컷, 수채화 번짐, 레트로 스티커, 픽셀아트, 네온 글로우 라인, 콜라주 스크랩북. 정의는 `lib/illustration/style-guide.ts`의 `STYLES`에 코드로 남겨둔다.
- 방문자에게는 이 풀에서 매번 무작위로 5개만 뽑아 보여준다 (전체 8개를 항상 다 보여주지 않는다).

## Boundaries

- 키워드 일러스트 생성기(미감 테스트)의 출력 전체에 적용된다. 모든 키워드가 같은 화풍 풀을 공유한다.
- 화풍 자체를 늘리거나 바꾸는 결정에는 이 문서를 다시 확인한다.

## Why

처음에는 미리캔버스 판매용 "통일된 화풍 세트"를 목표로 화풍을 하나로 고정했었다. 그런데 사용자가 앱의 컨셉을 "당신의 미감을 테스트하세요 — 남들과 같은 미감? 나만의 취향?"으로 명시적으로 바꾸면서, 애초에 비교 대상이 "같은 화풍 안의 구도"가 아니라 "서로 다른 화풍"이 되어야 한다는 게 분명해졌다.

처음엔 화풍 5개를 고정으로 다 보여줬는데, 사용자가 "순서를 섞어도 어차피 같은 5개라 지루하다"고 피드백해서 화풍 풀을 8개로 늘리고 그중 5개만 무작위로 뽑아 보여주는 방식으로 바꿨다. 매번 다른 조합이 나와야 재방문했을 때도 신선하다.

## Reconsider when

- 미리캔버스 판매용 세트를 다시 준비하게 될 때 (그때는 화풍 통일이 다시 필요할 수 있다 — 이 결정 이전의 근거를 참고).
- 풀 안의 특정 화풍이 압도적으로 인기가 없어서 빼거나 교체하고 싶을 때.
- 풀이 너무 커져서(예: 20개 이상) 무작위 5개가 서로 안 겹치는 경우가 잦아지면, 득표가 화풍마다 고르게 안 쌓일 수 있다 — 그때는 풀 크기나 노출 방식을 재검토한다.

## Still-rejected alternatives

- 화풍 통일 (최초 결정) — 판매용 세트에는 유리하지만, "미감 테스트"라는 지금 컨셉과 맞지 않아 사용자가 명시적으로 뒤집었다.
- 화풍 5개 고정, 노출 순서만 셔플 (직전 결정) — 순서를 섞어도 매번 같은 5개만 나와서 지루하다는 피드백으로 8개 풀 + 무작위 5개 추출로 대체했다.
- 완전 자유 생성(화풍도 구도도 무작위) — 비교 기준이 없어져 투표 결과를 해석하기 어려워질 것으로 판단해 기각.
